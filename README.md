# Todo API Client

Консольный клиент для работы с REST API JSONPlaceholder

## Возможности

- Просмотр всех задач
- Поиск задачи по ID
- Просмотр выполненных задач
- Просмотр невыполненных задач
- Просмотр задач пользователя

## Используемые технологии

- Python
- Requests
- REST API

##

## Как запуститть

```bash
pip install -r requirements.txt

python main.py
```

## Источнк данных

https://jsonplaceholder.typicode.com/todos
